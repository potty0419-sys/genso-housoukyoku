# 【仕様】元素騎士放送局（POC）

作成: 2026-11-15（Claude 設計）／実装: Codex／フォルダ: `~/Documents/app_genso_housoukyoku`

## 目的
元素騎士オンラインのプレイヤーが、ブラウザで「ふらっと開いて、片手間に置いておける」場所を作る。ポッティの配信・動画への入口にもする。

- 配信予定をトップに出す（ポッティの配信へ誘導）
- 最近の人気動画を並べる
- パーティメンバー募集の掲示板（実際に使える作り）
- ファンアプリ・ツールのまとめ
- 金策・ドラタワ・レベリング中に横に置いておける「ながら部屋」

## 前提
- 元素騎士は旧体制のサービスを終了し、新体制でのリリース準備中。公式情報は作らない（サンプル・リンク枠のみ）。サイト内のデータは **すべて「サンプル」と明記**。
- POC はサーバー不要の静的サイト（HTML/CSS/JS、ビルドなし）。`python3 -m http.server` で動く。後で GitHub Pages / Cloudflare Pages 等の無料静的ホスティングに載せられる形。
- 掲示板の保存先は差し替え可能な「ストレージ層」にする。POC は localStorage。本番用に Supabase のテーブル定義（SQL）と接続の雛形を `docs/` に置くが、**適用・接続はしない**。

## デザイン
- 「放送局」らしさ: 上部に ON AIR / 次の配信までのカウントダウンの帯、局のロゴ風タイトル「元素騎士放送局」。
- 配色: 元素騎士オンライン公式を参考に、深い紺 × ロイヤルブルー × 金。ダーク基調（ゲームの横に置いても眩しくない）。ライトモードは淡い背景 × 紺文字。ポッティ自身の配信・動画バッジだけ蛍光ライム色を残す。
- スマホ幅〜PCまで対応。PC では「ながらモード」（幅 420px の縦長レイアウト）に切り替えられる＝ゲーム画面の横に細く置ける。
- 文字は日本語。本文は OS 標準のゴシック体。ロゴ・h1・h2 と中央の局名は明朝体、暗色テーマでは金色、淡色テーマの見出しは紺色。外部フォントの読み込みは行わない。

## 画面（ハッシュルーティングの1ページアプリ）
1. **トップ（#/）**
   - ON AIR 帯: 配信中なら「LIVE」、なければ次の配信までのカウントダウン。
   - 配信予定リスト（data/schedule.json: 日時・タイトル・内容タグ・URL）。過去の予定は自動で隠す。カレンダー追加（.ics ダウンロード）ボタン。
   - 掲示板の新着募集 3件、人気動画 4本、ギルド防衛戦の次の開催までのカウントダウン（時刻は設定ファイルで変更可、サンプル値）。
   - お知らせ枠（新体制の状況など、data/news.json、サンプル）。
2. **動画（#/videos）**
   - data/videos.json（YouTube ID・タイトル・再生数・公開日・種別=配信/切り抜き/解説・タグ）。
   - 並べ替え: 人気順 / 新着順。絞り込み: 種別、タグ（ビショップ・ドラタワ・金策…）。
   - クリックで youtube-nocookie の埋め込みをモーダル表示。
3. **パーティ募集掲示板（#/board）** — 実運用を想定
   - 投稿項目: 目的（ドラタワ初級/中級/上級・ギルド防衛戦・レベリング・金策・ボス討伐・その他）、募集する職業（複数選択: ファイター/ナイト/ウィザード/ビショップ/クレリック/モンク/シーフ/アサシン/その他。職業一覧は設定ファイルで変更可）、推奨レベル（下限〜上限）、開始（今すぐ／時刻指定）、所要時間の目安、人数（現在/定員）、集合場所・チャンネル、ゲーム内キャラ名、コメント（140字）。
   - **期限切れ**: 開始時刻＋所要時間（既定1時間）を過ぎたら自動で「終了」になり一覧から消える（「終了も表示」で見られる）。投稿者は「締切」「人数更新」ができる。
   - **絞り込み**: 目的、自分の職業（その職を募集している投稿だけ）、自分のレベル（範囲内だけ）、時間帯（今すぐ/1時間以内/今日/今夜21時〜）。並びは開始が近い順。
   - **荒らし・トラブル対策**（POC で動く形で入れる）:
     - 投稿の連投制限（同じブラウザから3分に1件）、同じ内容の重複投稿を弾く。
     - NGワード（設定ファイル）、コメント内の URL・電話番号・メールっぽい文字列は投稿不可（外部誘導・個人情報対策）。
     - 「通報」ボタン: 通報3件で自動的に非表示（POC はブラウザ内で再現）。
     - 編集・削除は投稿時に発行する削除キー（ブラウザに保存）で行う。ログインなし。
     - 連絡はゲーム内で（DM機能は作らない）。「参加したい」ボタンは数だけ表示。
   - 本番化メモ（docs/board_operation.md）: 保存先を Supabase にする場合のテーブル・RLS・投稿レート制限・通報の運用フロー・利用規約に書くこと。
4. **ファンアプリ・ツール（#/tools）**
   - カード一覧（data/apps.json）: 名前・作者・説明・状態（公開中/開発中/構想）・リンク。サンプルとしてポッティ製の「エレメンタルフォース」「元素素材発掘」「元素騎士NFT図鑑（構想）」と、外部ツールの空き枠。
   - サイト内ミニツール:
     - **還元率・換算メモ**: mR ⇔ ドル換算（10000mR=1$ を初期値、変更可）と、売買の還元率（買値・売値から%）。
     - **ドラタワ コイン計算**: 1回あたりのコイン数・現在枚数から、1000枚までの残り回数・日数。
5. **ながら部屋（#/lounge）** — 片手間に居やすい空間
   - 周回カウンター（ドラタワ・レベリング等、ボタン1つで+1、ドロップのメモ、ブラウザ保存）。
   - 作業タイマー（持ち回り約1時間など、終わったら音なし・画面のフラッシュで通知。プリセット: 30分/1時間/バフ切れ等）。
   - 今日の稼ぎメモ（開始・終了の所持mRから差分と時給を出す）。
   - ひとことボード（掲示板と同じ仕組み、40字、24時間で消える。「ドラタワ周回中」「金策なう」など今の状況をつぶやける。荒らし対策は掲示板と共通）。
   - 次の配信・防衛戦のカウントダウンを常に表示。
6. **はじめての人へ（#/guide）**（おすすめ機能）
   - 用語集（ドラタワ、持ち回り、傭兵、mR、ベースSR など。サンプル文）。
   - ポッティの解説動画への導線。

## おすすめ追加機能（POC ではトップに「準備中」として枠だけ）
- ギルド紹介・メンバー募集板（パーティ募集と同じ仕組みで「ギルド」種別）
- 今週のアンケート（次に配信してほしい内容）
- 相場メモ（ユーザー投稿の価格メモ、日付付き）

## データの持ち方
- `data/*.json`（schedule, videos, news, apps, config）。config に職業一覧・目的一覧・NGワード・防衛戦の時刻・換算レート初期値。
- 掲示板: `js/store/` に `Store` インターフェース（list/create/update/remove/report）。`LocalStore` を実装、`SupabaseStore` はコメント付きの雛形のみ。
- データ取得の案（実行しない）: 配信予定は手入力 or Googleカレンダー公開ICS、人気動画は YouTube Data API（チャンネルの動画を再生数順に取得、1日1回の静的JSON生成）。docs/data_sources.md に書く。

## 合格基準（Claude が検証する）
- `python3 -m http.server` で全画面が表示でき、コンソールエラーなし。
- 掲示板: 投稿→絞り込み→期限切れ（時刻を過去にして自動で消える）→通報3件で非表示→削除キーで削除、が動く。連投制限・URL入りコメント拒否が動く。
- 幅 375px（スマホ）と 420px（ながらモード）で崩れない。
- すべてのサンプルデータに「サンプル」表示がある。外部への通信は YouTube 埋め込みとサムネイル画像のみ。
